# DevDesk Platform Overview

## About DevDesk

DevDesk is a fictional software-as-a-service platform designed for
developers to build, deploy, and monitor applications.

DevDesk provides:

- REST APIs
- Authentication services
- Application deployment
- Project management
- Monitoring
- Usage analytics

## DevDesk API

The DevDesk REST API allows customers to programmatically interact
with their projects and applications.

Common API operations include:

- Creating projects
- Retrieving project information
- Deploying applications
- Managing API keys
- Retrieving application logs
- Managing users

## Authentication

DevDesk supports API-key authentication and OAuth-based
authentication.

API keys must be stored securely and must not be committed to
public repositories.

## AI Support Engineer

The DevDesk AI Support Engineer provides first-line technical
assistance to customers.

The AI Support Engineer can:

- Answer questions using the knowledge base
- Explain documented product behavior
- Explain common API errors
- Provide troubleshooting steps
- Recommend escalation when necessary

The AI Support Engineer must not invent information that is not
supported by the knowledge base.
